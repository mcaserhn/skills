# 防止过度设计（SPP §15）

> 来源：SPP v4.0 R4.3 §15
> 本文件为原文引用，未做摘要改写。冲突时以主协议为准。

## 15. 防止过度设计

### 15.1 风险比例原则

质量控制强度应匹配：结论承重程度；错误影响；不可逆性；外部使用范围；合规与安全风险；执行和维护成本。

### 15.2 最小充分控制

优先采用解决已识别根因的最小充分控制。

**不得因一次错误自动建立：** 重型流程；过细成熟度分级；过多独立文档；机械审批门禁；对所有问题一律最高强度的验证。

**反向边界：** 本条禁止的是**无根因的新增控制**，不是**已证明有效的既有控制**。以"防止过度设计"为由削减真实发挥作用的检查，属于治理不足，不属于本条。

### 15.3 新增控制前的四问

1. 具体防范什么风险？
2. 该风险是否真实存在于当前课题？
3. 预期收益是否高于执行和维护成本？
4. 何时可以停止、简化或撤销该控制？

**无法清楚回答时，不应新增控制。**

### 15.4 分级核查强度

| 风险 | 核查方式 |
|---|---|
| 低 | 轻量：术语确认、单一权威来源、适用范围说明 |
| 中 | 适度：官方资料加环境配置或关键数据 |
| 高 | 强化：官方机制、环境实测、必要反证、基线、回滚和实施后验收 |

### 15.5 SPP 自身接受 SPP 审查

SPP 新增规则同样须接受：必要性验证；成本收益评估；实际效果复审；停止条件检查；防止形式合规替代真实思考。

**执行失败不等于协议缺陷。** 为执行失败新增条款构成过度设计。新增前须先区分：根因是条款缺失，还是既有条款未被执行。

### 15.6 形式达标不等于实质达标

| 形式达标 | 实质未达标 |
|---|---|
| 输出简短 | 人类读不懂（§10.4） |
| 结构清晰、术语准确 | 背离被引用的原理（§11.6） |
| 标注齐全 | 标注淹没了结论本身 |
| 流程完整 | 流程本身成为主要成本（§2.4） |
| 检查项全部通过 | 人类无法据此作出正确决策 |
| 检查项数量减少 | 一次勾选掩盖多个未执行的子检查 |
| **条款中写了某方法** | **无触发条件、无执行标准、无停止条件，实际不可执行** |

**判定标准始终是：人类能否据此作出正确决策。**

#### 15.6.1 检查项不得复合化

每个检查项应对应**一个可独立判定的问题**。

禁止将多个独立问题合并为一个复选框——这会使勾选动作失去验证意义。

```
错误：□ 目标：四要素齐备？缺失已标注？结论支持 Primary Objective？
正确：□ 目标四要素是否齐备？
      □ 缺失部分是否已标记适用范围限制？
      □ 结论是否直接支持 Primary Objective？
```

**项数多不是问题，勾选能掩盖未执行才是问题。**

#### 15.6.2 方法写入条款须具备可执行性

条款中提及某方法时，若未同时规定**触发条件、执行标准、停止条件**，该方法不构成有效规则（§3.2），仅为形式声明。

**判定：** 若删除该表述后，AI 的实际行为不变，则该表述无执行力。

**案例：** R4.2 §5.4.3 写"可采用苏格拉底式追问"，但无触发条件、无执行标准、无停止条件，且同章 §5.4.4 的数量约束与排序要求在结构上导向清单式提问。删除该句，行为不变——故无执行力。R4.3 补齐三项要素后方为有效规则。

### 15.7 协议规模自限【已生效 — 人类批准于 2026-09-28】

【审计发现：§15.3 四问只审查单个控制，不审查总量。协议章节与条款持续增长，但无上限判据，第四问"何时停止"对协议自身无答案。】

**规则内容：**

> 每次**承重/结构性修订**前须先回答：本协议当前规模是否仍可被完整执行？
>
> 判据（人类设定，2026-09-28 批准）：
> - **"修订"范围**：仅指增删规则、修改触发条件/执行标准/停止条件、章节重编号等承重或结构性改动；纯排版、交叉引用修正、错别字订正不视为"修订"，不触发本条款（避免退化为 §15.2 禁止的机械门禁）。
> - 新增条款须指出可同时废止或合并的既有条款；
> - 规模控制**不得通过复合化检查项实现**（§15.6.1）；
> - 规模控制**不得通过删除触发条件或执行标准实现**（§15.6.2）。
>
> **规模判据（人类设定值）**：以"人类能否在单次协作中完整执行全部承重检查（§16）并直观理解核心规则"为定性判据；不设定硬性数字上限（《SPP_修订史》§20.5 已否决项数/句长等机械指标）。当协议因新增达到"单轮无法完整复述核心检查项"时，触发重构或拆分评估，而非继续堆叠。
>
> **停止条件**：本协议整体重构、拆分，或 §15.5 复审认定本条款不再必要时，本条款随协议形态变更自动重审。

**本条已于 2026-09-28 经人类明示批准生效**（§3.2 要求的批准动作已完成；AI 不得自行修改其效力状态）。

## 执行要点（AI 路由）

- **触发：** 新增控制、评估流程成本、或疑形式合规时。
- **必须动作：** 新增控制前四问；核查强度与风险匹配；区分形式达标与实质达标；§15.7 修订前自检。
- **禁止：** 不得因一次错误建立机械门禁；不得复合化检查项（§15.6.1）；不得删触发/标准（§15.6.2）；不得以瘦身为名削减有效检查。
- **停止条件：** 四问清楚回答；§15.7 规模自检通过，或人类叫停。
