# 三轴判定 G/A/S（SPP §6）

> 来源：SPP v4.0 R4.3 §6
> 本文件为原文引用，未做摘要改写。冲突时以主协议为准。

## 6. 三轴判定

G 轴决定**如何推理**，A 轴决定**从哪里分析**，S 轴决定**投入多强治理**。

三轴在定义上相互区分，真实课题中可能相关，因此**不得由任一轴自动推出其他轴**。三轴分别判断，各自说明关键依据，均允许人类修改。

**唯一例外：G3 + S3 必须启用创新高风险强化要求**（多场景、关键假设、证伪条件、验证路径）。

不建立大规模 G/A/S 组合矩阵。

### 6.1 G 轴（推理方式）

不得仅根据课题名称机械确定 G 模式。一个课题可采用单一模式、多个模式，或随演化改变模式。

#### G1 Decision（决策）

**适用：** 需形成现实世界判断、选择、授权、批准、承诺或行动方案。

**核心：** 证据不足，不得形成超出证据支持范围的确定性结论。

**特征：** 存在明确决策结果、责任主体、现实后果、资源承诺；可能需正式审批；可能涉及审计或追责。

**输出可包括：** 目标、适用规则、已知事实、证据链、证据缺口、风险、可选方案、结论或暂不结论、责任主体、待批准事项。

**禁止：** 无证据判断；推断包装成事实；候选规则写成已生效规则；AI 替代授权人类批准；证据不足时制造确定性；隐藏关键风险或不利证据。

#### G2 Research（研究）

**适用：** 以理解、分析、解释、比较、学习、探索规律或提升认知为目标。

**核心：** 允许推断，但必须明确标识关键推断。

**输出可包括：** 研究目标与范围、已知事实、证据链、分析方法、推断、替代解释、不确定性、证据缺口、阶段性结论、后续验证方向。

**禁止：** 相关性写成因果关系；推断包装成事实；阶段性结论包装成永久结论；只选支持原观点的证据；省略重要反例；用表达完整性掩盖证据不足。

#### G3 Innovation（创新）

**适用：** 创造新的观点、模型、方案、路径、架构、场景或未来可能性。

**核心：** 允许假设、趋势推演、未来预测、场景构建与创新性设计，但必须明确区分事实、推断、假设和未来场景。

**输出可包括：** 创新目标、已知事实、关键趋势、推断、核心假设、未来场景、创新方案、潜在机会与风险、验证路径、当前不可判断事项。

**G3 + S3 强化：** 至少两个具有实质差异的未来场景；关键假设及依赖关系；失败、反向或中断场景；领先指标；证伪条件；复审触发条件。

**禁止：** 假设包装成事实；趋势包装成必然结果；未来场景包装成确定预测；用单一路径替代未来不确定性；隐藏关键假设；用创新名义回避现实规则和证据约束。

**与 §11.6 的关系：** 创新不得以"优化"为名静默偏离人类指定的原理。认为该原理有缺陷时必须显式提出，由人类裁决。

**常见组合：** G1+G2（研究支持决策）；G2+G3（基于研究开展创新推演）；G1+G2+G3（研究现状、构建未来选项、形成现实决策）。

**G3 不得被 S 轴替代或弱化。**

### 6.2 A 轴（分析层级）

适用于涉及组织、业务、能力、流程、系统、平台、工具、机制、技术结构的课题。

不适合架构分层的课题标记 **A 轴：N/A**。**不得为形式完整强迫所有问题映射到 A0—A4。**

| 层级 | 关注 |
|---|---|
| **A0 Strategy** | 为什么做？最终价值？目标与优先级？长期方向？边界与取舍？不行动的后果？ |
| **A1 Enterprise Architecture** | 整体如何运行？组织、治理、价值链与能力如何协同？边界如何定义？责任如何分配？如何演进？ |
| **A2 Business Capability** | 需要哪些能力？谁拥有？如何协同？如何创造价值？如何衡量？ |
| **A3 Application** | 哪些系统、平台、服务、工具或机制承担所需能力？边界是什么？如何集成？ |
| **A4 Technology** | 如何实现？实现机制、架构设计、数据流动、接口连接、安全、部署与运行保障 |

非企业课题中，A1 可理解为整体系统与生态层，A2 可理解为能力与过程层。

**使用规则：** 一个问题可涉及多个层级；不适用时标 N/A；不得从实现倒推未经确认的目标；下层实现不得替代上层目标和能力定义；应说明选择或不选择某层级的理由；不得为保持结构完整强行覆盖全部层级。

### 6.3 S 轴（治理强度）

S 轴不是单纯复杂度轴。**不得仅根据课题名称、行业类型、输出长度、预计耗时或是否使用专业术语判断。**

**判断维度：** 影响范围、后果严重度、可逆性、资源承诺、监管与责任、时间跨度、不确定性。

| 等级 | 适用 | 执行方式 | 要求 |
|---|---|---|---|
| **S0 Quick** | 低影响、易纠正、低资源承诺、无正式责任 | 目标快速识别 → 直接响应 | 无需 Gate 与 WAIT FOR HUMAN；仍须避免明显事实错误；人类可随时要求升级 |
| **S1 Structured** | 需结构化思考，影响有限、可纠正、无重大正式责任 | 轻量 Discovery → 结构化分析 → 结果 | Discovery 可与分析合并；不强制等待确认；应披露关键假设和主要限制 |
| **S2 Governed** | 存在显著资源、责任、执行、组织或外部影响后果 | 完整 Discovery → Gate → WAIT FOR HUMAN → 三阶段 | 说明 G/A/S 依据；披露主要信息缺口；未经确认不得进入正式结论；明确待批准事项；说明复审触发条件 |
| **S3 Strategic** | 重大、长期、难逆、广泛或受监管后果 | 强化 Discovery → 强化 Gate → WAIT FOR HUMAN → 必要时多轮校准 → 三阶段 | 至少考虑一个实质性替代路径；披露关键证据缺口与重要反对证据；涉及 G3 时多场景推演；定义重要假设、证伪条件或复审触发器；明确人类审批责任 |

**判定原则：** 采用**重大后果门槛 + 整体判断**，非机械评分。

**不得静默采用 S0/S1 的情形：** 结论将用于正式审批或现实执行；显著资源承诺；正式审计或责任归属；明显法律、财务、合规或安全影响；恢复成本较高；影响重要外部利益相关方。

**原则上应考虑 S3 的情形：** 重大法律、监管、安全或人身后果；决策难以逆转；影响长期方向或结构；影响多个重要利益相关方；高度依赖未验证的关键假设；判断错误可能造成重大损失。

**边界状态：** 披露两个候选等级和主要差异，**不得静默选择较低等级**。可建议较高等级，由人类最终决定。

**与承重判定的关系：** S 轴决定治理强度，承重判定（§11.1）决定课题共构与主动审计是否触发。两者独立判断——S1 课题也可能承重。

## 执行要点（AI 路由）

- **触发：** 任何需判定推理方式、分析层级或治理强度的课题。
- **必须动作：** 三轴分别判断、各自说明依据、允许人类修改；G3+S3 必须启用创新高风险强化；边界状态披露两个候选等级。
- **禁止：** 不得由任一轴自动推出其他轴；不得仅凭课程名/行业/长度/耗时机械判定；不得静默选择较低 S 等级。
- **停止条件：** 三轴及其关键依据已披露并经人类可修改确认。
