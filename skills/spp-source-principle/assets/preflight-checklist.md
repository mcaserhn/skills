# 输出前检查清单（SPP §16）

> 三态标注：**已确认**（源自 SPP §16）。每项对应一个可独立判定的问题（§15.6.1）。

**课题共构**

- [ ] 课题为承重课题时，是否已执行复述？
- [ ] 提议式问题是否均已标明出处？
- [ ] 人类叫停时未澄清的缺口是否已记录？
- [ ] 由未澄清缺口产生的适用范围限制是否已在结论中标注？

**目标**

- [ ] 目标四要素是否齐备？
- [ ] 缺失部分是否已标记适用范围限制？
- [ ] 当前结论是否直接支持 Primary Objective？

**被引用原理**

- [ ] 是否核实了人类引用的原理的实际主张？
- [ ] 替换测试：把该原理换成另一个，本方案会改变吗？（不变 = 未真正使用）
- [ ] 是否存在未披露的原理与通用实践冲突？

**表达**

- [ ] 关键结论能否用一句不含专业术语的话复述？
- [ ] 三态状态是否已标注（形式可变，状态不可省）？

**来源与证据**

- [ ] 主要来源是否权威且仍适用？
- [ ] 产品机制与环境事实是否已分离？
- [ ] 环境证据是否带时间截面与样本范围？

**反例与排他**

- [ ] 是否使用了"仅、全部、不影响、完全替代"等排他性表述？
- [ ] 若使用，是否已检查非目标集合？
- [ ] 是否存在未经检查的关键反例？

**数字**

- [ ] 数字属实测、计算、估算、目标还是验收值？
- [ ] 量化陈述是否来自实际执行结果，而非推测？

**降级与限定**

- [ ] 证据不足部分是否已降级为待验证或假设？
- [ ] 限定词、条件从句、例外是否完整保留？

**自身陈述**

- [ ] 关于工具执行结果的陈述是否属实？
- [ ] 关于本次修改范围的陈述是否与实际一致？

**一致性**

- [ ] 与前文及其他章节是否一致？
- [ ] 关键术语是否无歧义、无层级混淆？

**治理比例**

- [ ] 控制措施是否与风险相称？
- [ ] 是否存在过度设计？
- [ ] 是否存在以简化为名的治理不足？

低风险问题可轻量执行；承重结论必须完整执行必要项。

**全部勾选不等于输出有效**（§15.6）。
