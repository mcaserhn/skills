# AI 产出验收清单（定制扩展 · 产出后验证层）

> 三态标注：**待验证**（AI 提议，需人类验证）。本文为定制扩展，非 SPP R4.3 原文。冲突时以主协议为准。
> 依据：Veracode 2026 GenAI Code Security Report、Anthropic Best Practices、ThoughtWorks Radar Vol 34、DORA 2025。检索时点 2026-09-29。
> 定位：`assets/preflight-checklist.md` 管「AI 输出前自查」；本清单管**产出物验收**——AI（或任何人）交付工作成果后、人类接受前的核查层。人类与 AI 共用。

## 设计原则

1. AI 代码在通过验证前**按不可信输入处理**（Veracode 2026：安全通过率停滞 56%，语法正确率 ≈100%——「能跑」≠「安全」）。
2. 证据优先于断言：一切「已完成/已通过」声明附实际执行输出（§11.5）。
3. 控制强度与风险相称（§9）：S0/S1 走 A 组轻量三查；触及 B/C 组触发条件才升级。

## A. 通用门（所有产出，必查）

- [ ] **A1 证据实贴**：测试输出/命令返回/截图为实际执行结果，非推测性测量（§11.5 禁止估算冒充实测）。
- [ ] **A2 对照验收标准**：逐项核对 spec 的 Given-When-Then / 课题说明书 Success Criteria；未覆盖项标「待验证」而非视为通过。
- [ ] **A3 排他表述反证**（§12.1）：产出陈述含「全部测试通过 / 完全兼容 / 不影响现有功能」→ 检查非目标集合（旧调用方/边界输入/并发/回滚路径）。

## B. 代码产出专项（触发条件：本次交付包含代码变更）

- [ ] **B1 测试随变更**：新增/更新测试且实贴通过输出；测试应针对本次行为变更，非存量覆盖。
- [ ] **B2 防永绿测试**：抽查 AI 生成测试是否恒真恒过；高风险项用 mutation testing 检验测试有效性（TW Radar Vol 34 Trial）。
- [ ] **B3 安全四门**（AI 代码按不可信输入处理）：SAST（注入/加密缺陷）→ SCA（依赖 CVE 与真实性）→ secret scanning（AI 参与提交泄漏密钥率约为基线 2 倍）→ DAST；四门过闸前不合并。
- [ ] **B4 依赖核验**：AI 建议的新包逐一确认存在与来源（幻觉包 ≈20%，slopsquatting 风险）；优先复用仓库既有依赖。
- [ ] **B5 架构边界**：分层依赖方向、禁改区、API 契约未被突破；结构性约束优先用 linter/structural tests 机械核验，不靠目测。

## C. 承重升级项（触发任一即升级，不得静默走 A/B）

- [ ] **C1 不可逆操作**（migration/schema/生产配置/契约变更/force push，见 `references/13-coding-and-product-lifecycle.md` Coding 专属承重清单）→ 停止 → 人类批准 → 分阶段执行 → 实施后验收关闭证据链（§13）。
- [ ] **C2 S2/S3 课题产出** → 三态标注完整；关键结论可用一句不含专业术语的话复述（§16）；被引用原理已核实含替换测试（§11.6）。
- [ ] **C3 受监管/高风险/核心架构变更** → 人类终审，不适用任何「低风险自动通过」策略。

## D. 沉淀（验收后，可选但推荐）

- [ ] **D1 同型错误第二次出现** → 写入项目 AGENTS.md/CLAUDE.md 或本 skill 的 rule 层（OpenAI/Anthropic 官方实践）。
- [ ] **D2 生产事故** → 转为永久回归用例进入 evals 套件。
- [ ] **D3 评审意见** → 转为文档更新或工具规则，人类品味持续回灌系统。

---

## 执行要点（AI 路由）

- **触发：** 任何 AI 生成/修改的产出物交付验收时；人类要求「验收/检查这份产出」时。
- **必须动作：** A 组必查；按触发条件执行 B/C 组；核查结果逐项给出证据链接或明确标注未查项。
- **禁止：** 不得以「agent 自报通过」替代 A1 证据实贴；不得对 C 组项套用自动通过；不得把未查项默示为通过。
- **停止条件：** 全部适用项核销或人类明示接受残余风险（记录为管理决策）。
- **交叉引用：** 编码工作流 → `assets/spec-driven-workflow-template.md`；阶段产物定义 → `references/14-ai-era-sdlc-deliverables.md`；输出前自查 → `assets/preflight-checklist.md`。
