# 篇章与句法层规则（中文）

> `de-ai-flavor` 按需参考（L3）。何时加载：对**中文**文本做去味时，在**词汇层禁词表**（`references/02-banned-words-and-patterns.md`）之外，按本清单逐项检查篇章 / 句法痕迹。
> **适用范围（重要）**：本清单来自**中文语料实测**，仅适用于中文文本。**不得顺推至英文规则**——英文侧无对照数据，仍是经验清单（见 `references/02-banned-words-and-patterns.md`）。
> **来源**：改写自开源项目 **`lieflat-less-ai-tone`（MIT）**。其规则基于 283 万字对照语料（629 篇 = 300 生成 + 329 人类，5 个模型），对 26 项候选特征逐项检验，仅 11 项通过门槛。
> **证据等级**：🟢 语料验证（**高质量外部证据 · 待独立验证**）。原作者自陈三项局限——人类侧语料规模有限、语料不可核验、结论具时效性（模型持续向人类文风收敛）。**可用于修正明显矛盾与补缺，不可写成不可动摇的铁律。**
> **配套**：反向保护清单（看着像 AI 味、实测站不住、不得据此改写）见 `references/06-do-not-change.md`——**先读它**，避免越改越糟。

## 核心判断

> 通过检验的特征**集中于篇章与结构层面，而非词汇或标点层面**。

词汇层痕迹多半能被模型自身的改写直觉处理；**篇章层才是真盲区**。故本清单与词汇禁词表**互补，不可互相替代**。

## 改写规则（按区分力 R 排序）

R = 生成侧频率 ÷ 人类侧频率，越大越能区分。

### 11. 段首零回指评论（R=4.4）

非首段直接抛评论，不交代评论对象，读者得回上一段找。问题不在"不用衔接词"（段首衔接词总量人机相近），而在评论句**省掉了回指成分**。

- **触发标记**：非首段以「听起来 / 看起来 / 说白了 / 值得注意的是 / 更重要的是 / 关键在于 / 问题在于 / 意味着 / 不难看出」等评论语开头，且整句**没有**「这 / 那 / 其 / 此 / 上面」等回指上文的成分。
- **改法**：补一个回指词，或点明评论对象（多数加一个"这"字即够）。不动段落顺序、不动段内其他文字。
- **不改**：首段（无上文可指）；原文已有回指成分；对话与引语内部；比喻独立成段（人类比 AI 用得多——加"这"即可，不要删比喻）。
- ❌ 听起来像一条功能描述，其实底下换掉了更根本的东西。
  ✅ **这**听起来像一条功能描述，其实底下换掉了更根本的东西。

### 5b. 冒号：空转句引列表（R=9.4）

一句话不说内容，只宣布"下面有个列表"，以冒号收尾。

- **触发标记**：正文一行以冒号结尾，**紧接着是列表项或编号**，且该句去掉后信息不减。
- **改法**：把这句写成有内容的判断，或直接删掉让列表接上上文。**不能删列表项**。
- **不改**：引出人物原话（"他说：'明天再谈。'"）；小标题里的冒号；列表项内部的冒号；网址、代码和机器字段。
- ❌ 一套基础检查通常包括：
  ✅ 基础检查通常包含这几项。

### 7. 拟人化喻体（R=7.3）

把工具 / 系统 / 流程比作一个**理想化的人**，喻体在替作者抒情、不解释机制，后面常跟一串褒义修饰。

- **触发标记**：「像 / 相当于 + 一个 / 一位 + 职业角色（导师、秘书、助手、顾问、管家、审查员、实习生……）」，且喻体带褒义修饰，或后接"不仅……更……"。
- **改法**：换成这东西**实际做了什么**，或改用具体的人当喻体。
- **不改**：比喻本身（人类是 AI 的 2.4 倍；独立成段 8 倍）；具体的人当喻体（"像一个老师傅"）；喻体带来了正文没给的理解时（删掉比喻会漏信息则保留）。
- ❌ 它就像一位智慧的导师，不仅传授结论，更传授看待世界的多元视角。
  ✅ 它不只给结论，也讲看待问题的不同角度。

### 5a. 冒号：提示语引出（R=3.8）

冒号前是**不承担信息的提示语**。

- **触发标记**：冒号前是「一句话总结 / 核心是 / 关键在于 / 原因如下 / 结论 / 本质上 / 换句话说」这类提示语。
- **改法**：提示语不承担信息→删掉直接写内容；提示语在**承接上文**时→保留，只把冒号换成句号或逗号。
- **不改**：句中引出说明的冒号（"人擅长的是：判断业务逻辑"这类总说加分说，是规范用法）；同类冒号若人类内部用量差异过大，测不出稳定差异，不据此判断。
- ❌ 一句话总结：这个方案成本太高。
  ✅ 这个方案成本太高。

### 1. 翻案腔（不是 A 而是 B）（R=3.4）

先立一个读者并没有的误解，再把它推翻。

- **触发标记**：含「不是……而是…… / 并非……而是…… / 不在于……而在于…… / 与其说……不如说…… / 表面……实际…… / 看似……实则…… / 不是 A，是 B / 你以为……其实…… / 回头才发现 / 说到底 / 答案恰恰相反」。清单只是举例，**同一动作换任何字面都要改**。
- **改法**：直接从正面下判断——**先给判断，再给依据**。只有文章确实用材料走过了"从误解到修正"的过程，才允许写作者的自我修正，且不能套用上述固定句式。
- **不改**：否定项在**纠正一个真实存在的误解**、或两个分句各自承担不同信息时（"错误出在保存阶段，而不是上传阶段"）；引语与对话内部；§10.3 的前置话题壳里出现的"对……而言"另行按该条判断。
- ❌ 不只是工具的问题，而是思维方式的问题。
  ✅ 这是思维方式的问题。

### 9. 禁用起手式（R=3.2）

- **触发标记**：段首 / 句首「说白了 / 说穿了 / 先说结论」。
- **改法**：删掉，直接给判断。
- **不改**：引语与对话内部（复述他人原话）；作者在其他段落一贯如此、风格样本显示这是他的真实口癖；确需在长文开头交代阅读路径时，只把"先说结论"并入后句，不删该段。
- ❌ 说白了，这个项目没有足够的预算。
  ✅ 这个项目预算不足。

### 6. 序数词当小标题（R=3.1）

AI 爱把「一、二、三」当小标题给全文编号，通篇排到底——**模板感最强**的形态。小标题本该说明"这一节讲什么"，编号顶在最前把说明挤到次要位置。

- **触发标记**：小标题（`#` 开头，或独立成行的加粗文本）以「一、二、三」或「第一、第二」编号，且**连续 ≥3**。
- **改法**：**只删编号**，保留小标题原有文字。不改措辞、顺序、层级。
- **不改**：正文里的「首先……其次……最后」及句中的「第一，」「一方面」（与人类无差别，**不是 AI 痕迹**）；确按步骤 / 时间 / 法规条目组织且编号承担指代（"见第三条"）；Markdown 有序列表（`1.` `2.`）；只有一两个编号、未构成通篇编号。
- ❌ `## 一、先找出模糊在哪里` / `## 二、把需求写成六个模块`
  ✅ `## 先找出模糊在哪里` / `## 把需求写成六个模块`

> 词汇表侧（`references/02-banned-words-and-patterns.md`）同步收录本条；正文连接词的保护也在那里明示。

### 4. 破折号滥用（R=3.0）

用破折号制造"停顿后揭晓"，或插入不必要的补充。

- **触发标记**：破折号用于揭晓式停顿（"答案其实很简单——专注"）或插入非必要补充。
- **改法**：直接写完整句子，或改用逗号、句号。
- **不改**：句意确有需要时（作者本来的标点习惯可作依据）；**用户风格样本里本来就爱用的**（样本优先，见 `references/01-fidelity-guardrails.md` 第 9 节）；引语内部的原有标点。注意**分模型差异极大**（某些模型达人类 5 倍，另一些几乎不用），不要按"某个模型的味"套判断。
- ❌ 他找到了一条路——一条所有人都忽略的路。
  ✅ 他找到了一条别人都没注意的路。

### 10. 翻译腔（只保留五种）（R=2.6–5.3）

翻译腔本身**不等于 AI 味**——被动句、名词化、长句都是现代汉语书面语的正常写法，人类同样这么写（这些见 `references/06-do-not-change.md` 反向保护清单）。**只处理下面五种**；触发标记之外的表达，即使读来生硬，也必须原样保留。

1. **过长前置定语**：中心词前修饰超过十五字，或"的"字连续出现两个以上。
   改法：在原段落内拆成两个分句，不移动信息。同类：".……的……的……"连用承接英文所有格（"完成了对系统的稳定性的检查"→"检查了系统稳定性"）；名词前"一个/一种"与另一数量词叠加（"一个关于用户增长的一套新的方法"→"一套新的用户增长方法"）。不改：专名、法规 / 标准全称、字段名等**固定称谓**（拆开后指代会变模糊）；引语内部的原有措辞。
2. **"当……时"前置时间从句**："当"开头、以"时，"收尾、中间是完整主谓结构。
   改法：删"当"和"时"，让从句直接作前一分句。不改：确需标示时点、删后时间关系变模糊；"的时候"这类口语说法。
3. **前置话题壳**：句首「对于……来说 / 对……而言 / 就……而言 / 关于…… / 在……方面」，而后面句子本以此对象为主语或宾语。
   改法：把对象直接放到主语 / 话题位，删掉壳子。不改：确需限定讨论范围、删后会被读成全局断言时。
4. **句首连接词当路标**：段首 / 句首「然而 / 因此 / 此外 / 与此同时 / 换言之 / 总而言之」，尤其相邻段落连续这样开头。
   改法：把连接词移到主语后，或换成"不过 / 其实 / 也"这类更口语的说法。不改：论证确需在转折处立显式路标时。
5. **"这意味着 / 这表明"式复述句**：一句以「这意味着 / 这表明 / 这说明 / 换句话说」开头，且后面与前一句同义。
   改法：并入前一句，或删掉提示语只留结论。不改：后面确给出前句推不出的新结论时。

- ❌ 当所有人都能用 AI 写文章时，内容本身就不再是竞争优势。
  ✅ 所有人都能用 AI 写文章，内容本身就不再是竞争优势。
- ❌ 留存率涨到了 72%。这意味着产品找到了 PMF。
  ✅ 留存率涨到 72%，产品找到了 PMF。

> 同一句命中多条时，按出现顺序靠前的条目改，改完不再叠加。

### 3. 相邻句结构同款（R=2.0）

连着几句用同一句法骨架，逗号位置、成分顺序、收尾方式都一样。单看每句都通顺，连起来像填表。

- **触发标记**：相邻 ≥2 句，逗号数量相同、成分顺序相同、长度接近（典型是"主语＋动词＋宾语，＋补充说明"连续复现）。
- **改法**：打散其中一句的句法（合并 / 拆分 / 换语序 / 改短句）。只改句内，不动段落顺序，不删信息。
- **不改**：清单式段落本就该整齐时（操作步骤、并列条款）；对话和引语；散文、小说的有意排比。
- ❌ 这个功能上线后用户反馈很好。团队的开发效率提升明显。下一步的优化方向已经确定。
  ✅ 这个功能上线后用户反馈很好，团队开发效率也提升了。下一步优化什么，已经定了。

> 一段里并排三个以上平级案例时，可合并同类项或把次要的压缩成半句（信息不删，只改主次）。**但"恰好凑三个"是错觉**——实测三案例占比人机无差别，只在明显凑数时才处理；叙事推进不算，不要动。

### 2. 顿号并列过密（R=1.8）

一句里用顿号串起三项以上并列，塞进一整份清单。

- **触发标记**：一个分句内出现两个以上顿号，连起三项以上并列成分。
- **改法**：能概括就别逐项列；必须保留三项以上时，**改变其中一项的句法**，不让它们排成同一结构。不得改动原有列表结构或删必要项。
- **不改**：材料本身必须完整列出时（法规条目、配置项、财务科目）；Markdown 列表内部；**句内同构排比**（"提升效率，降低成本，优化体验"——人类用得不比 AI 少，见 `references/06-do-not-change.md`）。
- ❌ 无论是初创公司、中型企业，还是大型集团，都能从中受益。
  ✅ 各种规模的公司都能用。

### 8. 把已有数据写回概括表述（R=0.35，反向）

AI 靠抽象概括、人类靠具体材料（数字密度人类是 AI 的 2.8 倍）——这是**覆盖面最广**的一项差异，也是整篇的底色。但本 skill **不能补原文没有的信息**，所以这条只做一件事：**原文已给具体值时，不许用概括词盖掉它。**

- **触发标记**：句中用「显著提升 / 大幅增长 / 明显改善 / 效率的提升 / 大量 / 众多」等概括说法，而**同段或相邻段已写着**对应具体数值 / 时间 / 对象。
- **改法**：把已有具体值提到概括词位置。**原文没有具体数据时，只恢复动词，不许自己编数字。** "完成了对……的……""实现了……的提升""进行了……的优化"这类名词化结构也在此条，改法是恢复动词。
- **不改**：原文确实只有概括、没有具体材料时——不能补，也不能因"太抽象"删句；可在输出后提示作者"此处材料稀薄"。
- ❌ 新系统实现了效率的提升。处理时间从两小时缩短到四十分钟。
  ✅ 新系统把处理时间从两小时缩短到四十分钟。

## 验收（改写后逐项复查）

- 每一处改动都能明确对应**本文件某条编号规则**或 `references/02-banned-words-and-patterns.md` 禁词表；指不出对应规则的改动**必须撤销**。
- 改动**未落在** `references/01-fidelity-guardrails.md` 第 1.1 节的四类上下文边界上（标题 / 专有名词本身 / 元语言指称 / 引文与对话内部）。
- 所有**未命中规则的句子逐字保留**；未顺便润色相邻文字。
- 原文标题层级、章节顺序、段落数量与顺序、列表 / 表格 / 引用 / 代码块位置**完全保留**。
- **没有**为"像人写的"补虚词、换代词、调句长、拆段落（见 `references/06-do-not-change.md`）。
- 改写后**每个实词都能在原文指出出处**；姓名、数字、日期、引语、来源、因果，任一指不出出处者**必须撤销**。

- **停止条件**：全部未命中规则的句子逐字保留、每处改动可指向具体规则、实词可溯源——三条同时满足方可输出。
