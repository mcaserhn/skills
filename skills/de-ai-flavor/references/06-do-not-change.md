# 反向保护清单（不作为改写理由）

> `de-ai-flavor` 按需参考（L3）。**何时加载：任何改写动作开始前先读本文件。**  
> **性质**：以下特征**看着像 AI 味，实测站不住**，**不得据此改写**。本清单与改写规则同为**硬约束**，不是参考——它的作用是防止"越改越不像人"。  
> **来源与证据等级**：🟢 语料验证（**高质量外部证据 · 待独立验证**），同 `references/05-zh-syntax-and-structure.md`。均来自中文对照语料（283 万字 / 629 篇）。  
> **适用范围**：**仅中文**。英文侧**另有独立清单**（不是本清单的译文）见 `references/08-en-do-not-change.md`——两侧不得互推。

## 核心风险

执行者（人或 AI）若按"AI 味 = 整齐、无虚词、无口语、无设问"的直觉去改，会把**人类的自然特征当成 AI 味删掉**——结果**比不改更不像人**。本清单是解药：**下列各项一律保留。**

## 十项「不作为改写理由」

| #  | 特征                    | 为什么不能改（实测）                                                                                  |
| -- | --------------------- | ------------------------------------------------------------------------------------------- |
| 1  | **句长、段长不够参差**         | 与人类无差别（R≈0.87 / 0.94）。不要为"制造节奏"调句长或拆段落                                                      |
| 2  | **单字虚词偏少（就 / 很 / 了）** | AI 确实偏少，但**方向是补不是删**；补虚词无法验收，易把正式文改成口语                                                      |
| 3  | **反复写全称、少用代词**        | 实测**人类**比 AI 更常重复同一名词                                                                       |
| 4  | **被动句**               | 抽象被动（"被认为 / 被视为"）远低于收录门槛；是正常汉语书写                                                            |
| 5  | **名词化、长句本身**          | 现代汉语书面语正常写法，人类同样这么用                                                                         |
| 6  | **正文里的"首先……其次"**      | 与人类无差别。仅小标题编号在射程内（见 `references/05-zh-syntax-and-structure.md` 第 6 条）                       |
| 7  | **句内同构排比**            | "提升效率，降低成本，优化体验"这类人类用得不比 AI 少。只处理**句间**重复（`references/05-zh-syntax-and-structure.md` 第 3 条） |
| 8  | **问句 / 设问 / 问句小标题**   | 正文问句**人类远多于 AI（17 倍）**，删掉更不像人写                                                              |
| 9  | **比喻本身、比喻独立成段**       | 人类用得比 AI 多（2.4 倍；独立成段 8 倍）。只处理"理想化拟人喻体"（`references/05-zh-syntax-and-structure.md` 第 7 条）   |
| 10 | **抽象名词配具体动词**         | "时间替他保管了细节"这类两边都几乎不写，不构成区分                                                                  |

## 使用纪律

- **风格文档优先**：若同目录有目标风格文档（写作风格指南、`语言DNA.md` 一类），先读它；**风格文档与本清单冲突时以风格文档为准**——那是目标作者的真实写法，不是 AI 痕迹（例：作者本来就爱用破折号，就不该按破折号条删）。
- **判据是可定位的触发标记，不是频率高低**：不要按"某个模型的味"去套判断；同一特征在不同模型量级差异很大，只按触发标记逐句认。
- **体裁服从**：学术、新闻、公文等不必强加"我 / 你"，也不必拆短段；对话体、口语体、文学体裁按原有风格，不统一改写。
- **不在范围内**：文章框架（标题层级 / 章节顺序 / 段落顺序 / 列表 / 表格 / 引用 / 代码块位置）；代码块与外语段落；引文；对话与引语内部。

> 与 `references/05-zh-syntax-and-structure.md` 的关系：**05 说"改什么"，本文件说"什么绝不改"。**两者冲突时——例如 05 的某条可能诱使你删掉问句或比喻——**以本文件为准**（保留）。

---

**执行要点**

- **触发**：任何改写 / 去味动作开始前。 
- **必须动作**：对已列入本清单的 10 项，**逐字保留**；有风格文档时先读并以其为准。
- **禁止**：以"太整齐 / 太多虚词 / 有设问 / 有比喻 / 有被动句"为由删改；用本清单的英文侧推论改写。
- **停止条件**：确认本次改动**未触及**本清单任一项，方可输出。
