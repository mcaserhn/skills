# 取证打分（AI-Check · 中英双语）

> `de-ai-flavor` 按需参考（L3）。何时加载：用户问"这段像 AI 写的吗 / 打个分 / 给我个取证分析 / does this sound AI?"，或交付前要一份**可复核的诊断报告**。
> **性质**：本文件**只诊断，不改写**。诊断与改写是两条道——改写走 references/01 + references/02 + 对应语言的篇章层（中文 references/05 / 英文 references/07）+ references/09。
> **前置**：本文件的排除判据来自反向保护清单（中文 `references/06-do-not-change.md` / 英文 `references/08-en-do-not-change.md`）。**未先读它们就打分会系统性偏高**。

## 0. 边界（先读）

1. **不改写**：报告只给分、给证据、给判定，不交出替换全文。用户要改写时另行按 01–09 执行。
2. **不属于"去味"**：本文件是**评价工具**。一次评分的结论不能反过来成为改写理由——只有落到 01/02/05/07/09 的具体条目上，改动才成立。
3. **允许"判不了"**：证据不足时给 `Uncertain` 或降 `CONFIDENCE`，**不要**为了给结论而凑分。这与 §1 白名单默认同一精神——**拿不准就是拿不准**。
4. **零假阳性项优先**：`references/09-format-and-artifacts.md` A 组（机器残留标记）命中即直接定性，不参与下面的打分平均。

本文件的骨架借鉴开源项目 **`harshaneel/humanize` 的 `ai-check` 子技能**（MIT）。但它的判据**与 `de-ai-flavor` 的对照语料证据直接冲突**，故逐条重新校准。**不得直接照搬外部 rubric**：

| 外部 ai-check 的信号 | `de-ai-flavor` 的判定 | 本文件处置 |
|---|---|---|
| Signal C **hedge density** 计入 | `references/08-en-do-not-change.md` 第 4 条：hedge 在 **全部 6 个模型上均 <1**（0.50–0.92），是全库唯一模型间无翻转的 hedge 类特征；references/06 第 2 条同向 | **剔除 hedge**。真靶子改为「**以确定语气说空话**」（见信号 C） |
| Signal E 把 **passive construction** 列为具体性缺失 | references/08 第 6 条：无施事被动 **AI ≈0.5×、人类多用 2 倍**；references/06 第 4 条同向 | **剔除被动**。具体性只看「论点有无数字 / 名称 / 动作」 |
| Signal G **em dash 超预算**为强信号 | references/09 C 组：英文 em dash **2026 年已退潮**；references/05 第 4 条：**中文破折号仍成立（R=3.0）** | **英文剔除、中文保留**（不跨语言） |
| Signal G **semicolon** 为 flag | 本 skill 中英文两侧均无该条证据 | 降为 ⚪ **提示项，不计分** |

| Signal H 「无第一人称」为强信号 | references/06 使用纪律：**体裁服从**，学术 / 公文不必强加"我 / 你" | **降权**：仅在语域明显该有第一人称时才计 |

## 2. 打分协议

**每类 0–3 分**，10 类，**满分 30**。

| 该类证据 | 得分 |
|---|---|
| 无命中 | 0 |
| 一个弱实例；或只有"感觉像"而指不出具体片段 | 1 |
| 一个中等实例；或两个以上弱实例 | 2 |
| 一个强实例；或两个以上中等实例；或四个以上弱实例 | 3 |

- **双重计数限制**：同一片段最多同时计入两个类别，且**同一类别内不得因同一片段计两次**。（例：`it is important to note that` 同时属信号 A 与信号 C，两处各记一次；但不得在 A 内记两次。）
- **语言门控**：中文文本只用中文侧触发标记，英文只用英文侧；混排两侧各自计入。**不跨语言套用**（与 references/02 语言处理规则一致）。
- **证据等级标注**：报告中每条证据都要带上本 skill 的证据等级（🟢 / 🟡 / ⚪）。⚪ 表示本 skill 无对照语料、来自外部检测文献，**只作方向性提示**。

## 3. 十个信号类别

### A. 词汇可预测性 · 依据 references/02

- **中文触发标记**：套话开场 / 收尾（"在当今…时代""在…背景下""综上所述"）、抽象大词（赋能 / 打造 / 闭环 / 抓手 / 打通）、助手腔客套。**注意**：references/02 已实测**中文词汇层痕迹弱**（区分力集中在篇章层），故中文侧 A 类**封顶 2 分**。
- **英文触发标记**：references/02 英文 buzzword 清单 + 套话开场 / 收尾 + 以确定语气说空话 + 助手腔。英文词汇层实测**很强（倍数 100×+）**，正常计分。
- **证据等级**：中文 🟡 / 英文 🟢（句法层证据，词汇倍数来自 HAP-E）。
- ✅ **不计**：领域术语（`authentication`、`compliance`）；references/08 第 2 条保护的普通动词（`used` / `wrote`）。

### B. 句长参差度 · 依据 references/06 第 1 条 / 无本 skill 英文证据

- **中文：权重 0**。句长参差度与人类无差别（R≈0.87），据此判断等于制造伪信号。可报"句长分布"作事实描述，**不计分**。
- **英文**：可报连续三句长度差 ≤4 词、或 150 词区间内无短句（<8 词）。证据等级 ⚪（HAP-E 未测 burstiness 特征，属外部检测文献常识）。
- ✅ **不计**：技术文档、法条、配置说明中天然等长的条目。

### C. 空话确定性密度 · 依据 references/02（真靶子）

**这是本文件对外部 hedge density 的替代项。** 靶子不是"软化"，而是"**以确定语气说空话**"。

- **中文触发标记**：毋庸置疑、不可否认、不言而喻、毫无疑问、无须赘言。
- **英文触发标记**：`it goes without saying`、`needless to say`、`it is undeniable that`、`cannot be overstated`、`there is no doubt that`、`it is clear that`。
- **证据等级**：🟡 社区共识 + references/02 校准说明。
- ✅ **保护（不计分）**：真 hedge —— 中文"可能 / 或许 / 在一定程度上"、英文 `might / perhaps / somewhat / arguably / tends to`。references/01 第 3 条：**表达真实不确定或条件许可时一律保留**。

### D. 结构模板化 · 依据 references/05 第 6 条 / references/07 第 10 条 / references/09 B 组

- **中文**：`一、二、三` 通篇编号小标题且连续 ≥3（**只删编号，保留小标题原文**）；正文"首先…其次"**不计**（references/06 第 6 条）。
- **英文**：`First… Second… Finally` 作通篇小标题骨架；几乎每段都出现三组并列。
- **格式层**（references/09 B 组，中英共用）：行内粗体小标题列表、粗体滥用、标题式大写、标题重复文档名、空标题、跳级 / 多个 H1、分隔线过密、emoji 当格式符。
- **证据等级**：中文 🟢（R=3.1）/ 英文 🟡 / 格式层 🟡（B 组）。
- ✅ **不计**：单组三项（references/07 第 10 条明示"不是判据"）；Markdown 有序列表；按步骤 / 时间 / 法规组织且编号承担指代的场合。

### E. 具体性缺失 · 依据 references/05 第 8 条

- **触发标记**：抽象论断无数字 / 名称 / 时间 / 动作（"许多组织已经采用…"）；概括词**盖掉**了同段已有的具体值（"实现了效率的提升。处理时间从两小时缩短到四十分钟。"）。
- **证据等级**：中文 🟢（数字密度人类是 AI 的 2.8 倍）。
- ⚠️ **硬约束**：本 skill **不得补原文没有的信息**（references/01 第 2 条）。报告只能指出"此处材料稀薄"，**不得给出示范句里的编造数字**。
- **剔除外部的 passive 判据**（见 §1）。

### F. 过渡词指纹 · 依据 references/02 密度判据 / references/05 第 10.4 条

- **中文**：段首"然而 / 因此 / 此外 / 与此同时 / 换言之 / 总而言之"，尤其相邻段落连续这样开头。
- **英文**：句首 `Additionally / Furthermore / Moreover / Notably / Consequently` 堆积（**预算 2 次**，超出才计）。
- **证据等级**：中文 🟢（R=2.6–5.3 之一）/ 英文 🟡。
- ✅ **不计**：孤立出现（references/08 第 10 条：**判据是密度，不是出现**）。

### G. 标点指纹 · 依据 references/05 第 4 / 5 条 · **不跨语言**

- **中文（保留，🟢 R=3.0）**：破折号用于揭晓式停顿或非必要补充，超预算（每 300 字 1 个）；冒号空转（`05` 第 5a：冒号前是不承担信息的提示语；`05` 第 5b：行尾冒号只宣布"下面有个列表"）。
- **英文：em dash 不计分**（references/09 C 组已退潮）。semicolon 仅作 ⚪ 提示。
- ⚠️ **两条独立结论，不得互推**：中文保留、英文退潮。
- ✅ **不计**：引出人物原话的冒号；小标题里的冒号；网址、代码、机器字段；句意确有需要时的破折号。

### H. 语域与人味 · 依据 references/06 第 8 / 9 条、references/08 第 3 / 4 / 7 条

这一类的**误报率最高**，必须逐项对照保护清单。

- **可计**：语域明显该有第一人称却全文无人称；口语体里通篇完整书面句（register collapse）；结尾出现模板化套话（"Let me know if you have any questions."）。
- **保护（一律不计）**：问句 / 设问（人类是 AI 的 **17 倍**）；比喻本身（**2.4 倍**，独立成段 **8 倍**）；最高级与确定性陈述；hedge 与 intensifier；脏话粗俗语（AI 低 **100 倍以上**）；无施事被动。
- **证据等级**：🟢（均出自本 skill 对照语料）。
- ⚠️ **体裁服从**：学术、新闻、公文**不必**强加"我 / 你"（references/06 使用纪律）。

### I. 修辞脚手架 · 依据 references/07 第 1 / 3 / 7 条、references/05 第 1 / 2 / 3 条

最像"好文章"的一类，也最容易被忽略——**不得因为文笔好就折价**。

- **英文**：现在分词状语从句（`07` 第 1 条，5.3× / d=1.38，🟢）；否定平行（`07` 第 7 条）；`that` 关系从句把主语拉长（`07` 第 3 条）。
- **中文**：翻案腔"不是 A 而是 B"（`05` 第 1 条，R=3.4）；相邻句结构同款（`05` 第 3 条，R=2.0）；禁用起手式"说白了 / 说穿了"（`05` 第 9 条，R=3.2）；拟人化喻体（`05` 第 7 条，R=7.3）。
- **证据等级**：英文 🟢（同行评审 + 本地复算）/ 中文 🟢（语料验证）。
- ✅ **保护**：句内同构排比（references/06 第 7 条）；具体的人当喻体（"像一个老师傅"）；单次否定平行确在区分两个真实选项。

### J. 格式与残留标记 · 依据 references/09

- **A 组（零假阳性 · 最高优先级）**：`contentReference`、`oaicite` / `oai_citation`、`turn0search0`、`[cite: 1]`、`[span_1](start_span)`、`grok_card`、`attached_file`、`ppl-ai-file-upload`、`:::writing` 等。
- **处置**：命中即**直接定性为机器生成痕迹**（不占 30 分，单独在报告顶部标出）。删前先确认来源不丢失（references/09 A 节 + references/01 第 6 条）。
- **B 组**：按密度判断，计入 D 类即可，本类不重复计分。

## 4. 混合署名叠加（AI-edited fraction）

与总分**独立**的另一维度，参照 EditLens（arXiv 2510.03154）以回归编辑量而非二元判作者的思路。看分布线索：

- 全文信号**均匀** → 纯 AI 生成
- 个别段落被打磨、其余粗粝 → 选择性 AI 编辑
- **AI 词汇聚在过渡与结论、正文具体** → AI 搭骨架 + 人填实质
- **首尾段polished、中段零碎** → 只编辑了书挡
- 文风中途变化（正式 ↔ 口语）→ 混合来源
- **一段集中了全部禁词、其余干净** → 单段 AI 内容插入

输出桶位：`纯人工(~0%)` / `轻度 AI 辅助(~10-30%)` / `混合署名(~30-60%)` / `重度 AI 编辑(~60-90%)` / `纯 AI(~100%)`。

## 7. 校准与检测上限（决定置信度上限）

**本 skill 自己的校准**（硬约束）：

- 中文文本 A / B 两类权重受限（references/02 词汇层痕迹弱 + references/06 第 1 条句长无差别）。**中文总分不得直接跨语言比较。**
- 命中的是保护项时不计分（§1）。报告必须跑 `保护项复核`。
- 体裁不匹配：references/07 的倍数是 **6 体裁（学术 / 博客 / 小说 / 新闻 / 口语 / 影视剧本）** 的 GPT-4o 单点值，**不含商务邮件、IT 方案与汇报、幻灯片**——不得当判据阈值。

**外部检测文献的天花板**（证据等级 ⚪，转载自外部 ai-check；决定置信度封顶）：

- **基座模型输出读起来像人类**：非指令微调的原始基座输出对当前 SOTA 检测器形同人工——检测器真正命中是 RLHF / 指令微调产物（礼貌性 hedge、结构化枚举、过度连贯）。若文本可能来自基座模型或轻量微调改写器，**置信度封顶"中"**。
- **迭代改写是天花板**：经一个或多个 LLM 反复改写的文本，会让 >90% 准确率的检测器大幅失效。用户提到"改写 / 润色过" → **全类降权**。
- **模型盲区**：DetectRL 基准记录 Binoculars 对 Claude 生成文本 AUROC 仅 ~55%（GPT-3.5 ~88%）。疑似 Claude 来源时，**低分要额外谨慎**。
- **风格线索是语料条件的**：SHAP 归因分析显示检测器依赖的风格特征是数据集特定的，不是稳定的机器作者信号。**不得锚定单一信号**，须跨类互证。
- **多语言严重失准**：检测器对非英文文本误判率高（有商业检测器准确率从 92% 掉到 12%）。**非英文文本不得给"高"置信度**，除非已做语言匹配校准。
- **短文本**：<100 词可用信号少，**置信度封顶"中"**。

> **脚本与报告的分工**：`scripts/ai_pattern_lint.py` 是**确定性**的那一半——正则能认、可进 CI、只报不改。本文件是**判断性**的那一半——处理脚本认不出的（具体性、语域、修辞脚手架、混合署名）。**两者结论不一致时**：脚本命中但报告判为保护项 → 以报告为准（脚本 `--show-protected` 也列了同一份排除清单）；报告命中但脚本无输出 → 属判断性信号，须给原文片段作证。

**执行要点**
- **触发**：用户要求"像不像 AI""打个分""取证分析"，或交付前需要可复核的诊断报告。
- **必须动作**：先跑 `scripts/ai_pattern_lint.py` 拿确定性结果；再按下表打分；**必填 `保护项复核`**；每条证据标证据等级。
- **禁止**：把 06 / 08 保护项计为 AI 信号；跨语言套用触发标记或总分；为给结论而凑分；在报告里给出替换全文或编造数字。
- **停止条件**：10 类均已判定（含"判不了"）、每处 >0 分都有原文证据、保护项已复核并明示不计分——三条同时满足方可交付。
